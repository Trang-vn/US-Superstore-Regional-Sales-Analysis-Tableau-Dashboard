# 📊 Superstore Sales Performance Dashboard  
**Independent Project | 2025**  
**Tools:** Tableau • Excel • Data Analytics  

---

## 📋 Overview  
Designed an interactive **Tableau dashboard** analysing Superstore sales and profit data across U.S. regions (2014–2018).  
The project demonstrates data visualisation, trend analysis, and business insight generation from raw data.

---

## 🎯 Objectives  
- Build a sales performance dashboard with dynamic filters.  
- Identify trends in revenue, profitability, and regional growth.  
- Provide actionable insights for inventory and marketing decisions.  

---

## 🚀 Key Insights  
- West region had the highest profit margin (15%).  
- Office Supplies category drove consistent sales growth.  
- Furniture segment showed high cost-to-revenue ratio.  

---

## 💡 Skills Demonstrated  
- Data Visualisation (Tableau)  
- Data Cleaning & Preparation (Excel)  
- Business Insight Generation
